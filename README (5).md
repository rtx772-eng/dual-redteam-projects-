## 📝 How to Use This Repo

1. Open the folder for your current month
2. Read the `README.md` — it has the objective and checklist
3. Do the work, add your code/screenshots/reports
4. Fill in the writeup sections in `README.md`
5. Commit to GitHub with a message like: `feat: complete project 01 - network scanner`
6. Update the progress table in this README
7. Log your progress in the `progress-tracker` repo
